\# Tomato Disease Detection Model



\## Project Overview

This model is part of the AgriSense Graduation Project.



It uses Deep Learning to classify tomato leaf images and detect possible diseases.



\## Features

\- Tomato leaf disease classification

\- Model training and fine-tuning

\- Model evaluation

\- Streamlit interface for predictions



\## Technologies

\- Python

\- PyTorch

\- Torchvision

\- Streamlit



\## Model Files

\- `best\_model.pth` - Initial trained model

\- `best\_finetuned\_model.pth` - Fine-tuned model

\- `class\_names.json` - Disease class names



\## Installation

Install the required packages:



`pip install -r requirements.txt`



\## Run Application

`streamlit run app.py`
